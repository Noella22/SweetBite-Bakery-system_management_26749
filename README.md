SweetBite Bakery Management System

This is my C# Windows Forms project for managing bakery products, customers, sales, orders, payments, inventory and reports.

How to Run the Project

Install Visual Studio and XAMPP.

Start MySQL in XAMPP.

Open phpMyAdmin and create a database named sweetbite_db.

Import the sweetbite_db.sql file into the database.

Open SWEETBITE_BAKERY_MANAGEMENT_SYSTEM.sln in Visual Studio.

Restore NuGet packages if needed, then build and run the project.

Important Notes

The project uses .NET Framework 4.7.2 and MySQL.

The database connection is in App.config. Change the MySQL username or password if needed.

The SQL file contains the table structures only, so a user account must be created before logging in.
